# Synthetic single-cell workflow demonstration

This folder is a visual test of the `top-journal-figure` skill. All cell coordinates,
expression values, and donor compositions are deterministic synthetic data and must not
be interpreted as scientific evidence.

Run with the bundled Codex Python runtime or any Python environment containing NumPy and
Matplotlib:

```powershell
python -B generate_figure.py
```

Outputs include editable SVG/PDF, a high-resolution PNG preview, the underlying CSV,
`figure-spec.json`, `palette.json`, and `qa.json`.
